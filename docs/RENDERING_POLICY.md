# Политика перерисовки GUI

Постоянно работающий интерфейс не должен показывать промежуточное пустое
состояние. Поэтому очистка bounds элемента перед каждой отрисовкой не является
обычным способом обновления.

## Неподвижные элементы

Для часов, чисел, индикаторов, графиков и других элементов с неизменными
границами применяются два допустимых варианта:

1. Непрозрачная перерисовка поверх старого изображения, при которой callback
   самостоятельно задаёт окончательный цвет каждого затронутого пикселя.
2. Дифференциальная перерисовка только изменившихся пикселей или прямоугольных
   фрагментов.

Фон перед таким обновлением не очищается.

Текущий циферблат использует дифференциальный вариант:

- секундная полоса дорисовывает только прирост;
- при уменьшении полосы цветом track закрашивается только исчезнувшая часть;
- цифра сравнивает маски семисегментного представления;
- новые сегменты рисуются первыми;
- цветом фона закрашиваются только сегменты, отсутствующие в новом значении;
- неизменившиеся сегменты не передаются на дисплей.

## Перемещение и перекрытия

Восстановление фона требуется, когда элемент:

- перемещается;
- скрывается;
- меняет размеры;
- является прозрачным и не может самостоятельно восстановить композицию;
- участвует в sliding-переходе окна.

NOG_C предоставляет две политики элемента:

```c
GNO_ELEMENT_REPAINT_RESTORE
GNO_ELEMENT_REPAINT_OVERDRAW
```

`RESTORE` является совместимым режимом по умолчанию. Для неподвижного
инкрементального виджета нужно выбрать `OVERDRAW` и обновлять его через
`gno_window_update_fast()`. Пока bounds и видимость не меняются, NOG_C вызывает
отрисовку без предварительной очистки. При перемещении или скрытии старое место
всё равно восстанавливается.

## Полная отрисовка

Полная очистка допустима при:

- первом появлении экрана;
- явной смене всего визуального оформления;
- переходе между окнами, для которого выбран такой эффект;
- восстановлении после ошибки или потери состояния дисплея.

Машина состояний определяет момент перехода между экранами, но политика
перерисовки внутреннего содержимого принадлежит самому экрану или виджету.
