# ProMicro nRF52840 test board

Статус: визуально идентифицировано, GPIO дисплея подключены пользователем  
Дата: 2026-07-23

## Наблюдаемая плата

- ProMicro/SuperMini form factor;
- nRF52840 QIAA;
- USB-C;
- выводы `B+`, `B-`, `RAW`, `VCC`, `GND`, `RST`;
- GPIO подписаны непосредственно как `005`, `008`, `017`, `020`, `100` и
  т. п.;
- SWD pads: `VDD`, `DIO`, `CLK`, `GND`;
- видимы кварцы 32 МГц и 32,768 кГц;
- J-Link подтверждает `PART=0x52840`, 1 МиБ Flash, 256 КиБ RAM и VTref 3,300 В.

Маркировка `100` означает `P1.00`, `020` — `P0.20`.

## Первый дисплей

- маркировка: `1.28" TFT Ver1.0`;
- разрешение: 240×240;
- controller: GC9A01;
- интерфейс: 4-wire write-only SPI;
- выводы: `RST`, `CS`, `DC`, `SDA/MOSI`, `SCL/SCK`, `GND`, `VCC`;
- отдельный вывод управления подсветкой отсутствует.

## Проверяемое подключение v1

| GC9A01 | nRF52840 | Silk |
|---|---|---|
| VCC | board VCC 3,3 В | `VCC` |
| GND | GND | `GND` |
| SCL/SCK | P0.20 | `020` |
| SDA/MOSI | P0.22 | `022` |
| CS | P0.24 | `024` |
| DC | P1.00 | `100` |
| RST | P0.11 | `011` |

`RST` дисплея намеренно не соединён с `RST` микроконтроллера.

## Ограничения первого теста

- SPI mode 0, MSB first, 1 МГц;
- RGB565;
- display power/backlight постоянно подключены к VCC;
- readback отсутствует, поэтому подтверждение выполняется визуально и по
  checkpoint firmware;
- перед повышением SPI frequency требуется успешный цветовой тест.

После подключения макетных проводов SWD на 1 МГц стал нестабилен. На 100 кГц
J-LinkOB устойчиво обнаруживает AHB-AP и Cortex-M4F, поэтому эта скорость
используется для bring-up. `P0.20` не совмещён с SWDCLK; это отдельные выводы
nRF52840.
