# Home Context для круглого экрана 240×240

`HOME_CONTEXT` — стартовый экран тестового GUI. Он следует визуальному языку
«Строгий контекст» и адаптирован к реальному круглому RGB565-дисплею, а не к
примерному mono1-профилю 256×256 из спецификации.

Экран показывает:

- статусы каналов `PH`, `TS`, `DET`;
- крупное локальное время `HH:MM`;
- субсекундную шкалу;
- контекст PUMP-2 с quality/status;
- переходы в список устройств и журнал событий.

Статические элементы рисуются при входе на экран. В steady state время и
секундная шкала обновляются дифференциально. Две нижние кнопки имеют визуальную
высоту 34 px, но их интерактивная область расширена до нормативных 44 px.

Тестовый PUMP-2 и статусы соединений не являются реальными данными. Это
явно ограниченный demo snapshot revision 1842, который нужен для проверки
композиции, навигации, quality и safety lifecycle до подключения транспорта.
