# 03. Геометрия 256 × 256

Все координаты даны как `[x, y, width, height]`, начало в левом верхнем углу.
Координаты целочисленные. Линии привязываются к физическим пикселям.

## Безопасные области

| Профиль | Постоянное поле |
|---|---|
| квадрат | 14 px слева и справа |
| круг, рабочие экраны | 26 px слева и справа |
| круг, верх главного | 37 px |
| круг, разделители | 28 px |
| круг, нижние счётчики | 54 px |

Не вычислять круг как `square + clip`. Для каждого профиля хранить полную
геометрию. Проверять углы маской окружности радиуса 128 px.

## Списки

Квадрат: 228 px ширины, строка 60–64 px, 3 полные строки после заголовка.

Круг: 204 px ширины, строка 55–56 px, не менее 3 строк; текст и meta меньше,
но hit target остаётся на всю строку.

Строки отделяются линией 1 px. Последовательность колонок:

`[иконка 19–24] [текст minmax] [мета auto] [стрелка 16–20]`.

## Масштабирование

Для другого разрешения не применять произвольный uniform scale к готовому
bitmap. Выбрать size class и пересобрать layout:

- `compact`: 240–280 px, текущие правила;
- `medium`: 320–480 px, добавляется третий уровень размера и больше строк;
- `large`: 480 px+, допустимы графики и плитки 2×N.

Семантические роли и порядок сохраняются, точные bounds принадлежат профилю.
