# ЦехоСенс — пакет реализации графики часов

Версия пакета: **1.0.0**  
Базовый холст: **256 × 256 px**  
Профили: **квадрат**, **круг**, **normal**, **ambient**  
Целевой минимум: **монохромный дисплей 1 bpp**, частичная перерисовка

Это визуальная спецификация принятого дизайна «Строгий контекст». Она дополняет
архитектурные документы ЦехоСенс и отвечает на практический вопрос: **что именно
рисовать, с какими размерами и как проверить совпадение**.

## Источник истины

При расхождении источников использовать такой приоритет:

1. эталонные кадры в `reference/screens/` и `reference/atlases/`;
2. токены и геометрия этого пакета;
3. правила компонентов и экранов этого пакета;
4. `reference/source/styles.css` и `App.jsx` как измеримый прототип;
5. старые `legacy-layout.json` и `legacy-manifest.json`.

В старом manifest указан `Roboto Condensed`, но принятые экранные кадры
отрисованы **Roboto**. Для часов источником истины является Roboto. Condensed
использовался только во внешней оболочке демонстрационного стенда.

## Быстрый маршрут для Codex

1. Прочитать `AGENTS_GRAPHICS.md`.
2. Реализовать токены из `tokens/strict-context.tokens.json`.
3. Реализовать примитивы и ограничения из `08_EMBEDDED_GRAPHICS_C.md`.
4. Воспроизвести главный экран по `03_LAYOUT_GEOMETRY_256.md`.
5. Добавлять компоненты по `04_COMPONENT_LIBRARY.md`.
6. Сверять каждый экран с PNG из `reference/screens/` при масштабе 1:1.
7. Выполнить `VALIDATION.md`.

Готовая формулировка первой задачи находится в `START_TASK_FOR_CODEX.md`.
Если в репозитории уже есть `AGENTS.md`, инструкции нужно объединить по scope,
а не перезаписывать существующий файл.

## Состав

- `01_VISUAL_LANGUAGE.md` — принципы и визуальная иерархия;
- `02_TOKENS_AND_TYPOGRAPHY.md` — палитра, шрифт, размеры, линии и интервалы;
- `03_LAYOUT_GEOMETRY_256.md` — точная геометрия 256 × 256;
- `04_COMPONENT_LIBRARY.md` — контракт графических компонентов;
- `05_SCREEN_CATALOG.md` — каталог эталонных состояний;
- `06_MOTION_PARTIAL_REDRAW.md` — анимация и частичная перерисовка;
- `07_SKINS_ASSETS.md` — сменные шкурки, ресурсы и совместимость;
- `08_EMBEDDED_GRAPHICS_C.md` — рекомендации для реализации на C;
- `09_CODEX_GRAPHICS_IMPLEMENTATION_PLAN.md` — порядок внедрения;
- `VALIDATION.md` — критерии готовности;
- `tokens/` и `layouts/` — машиночитаемые параметры;
- `icons/phosphor/` — SVG из используемой библиотеки Phosphor;
- `reference/` — исходник прототипа и эталонные кадры.

## Неподвижные решения

- Дизайн строгий, без декоративных виджетов, карточек, теней и скруглённых
  контейнеров.
- Главная иерархия: время → состояние часов → текущее устройство → два мира
  уведомлений и количество устройств рядом.
- Состояние нельзя кодировать только цветом.
- На круглом экране используется отдельная компоновка, а не обрезанный квадрат.
- Интерактивная область может быть больше нарисованного элемента.
- В normal-профиле время обновляется раз в минуту; остальные зоны — по событию.
- Во время перелистывания допускаются только белые контуры; финальный экран
  появляется после завершения жеста.

## Не входит в пакет

Пакет не определяет транспорт BLE/LoRa, паспорт устройства, безопасность команд,
маршрутизацию событий и хранение журнала. Он задаёт только графический контракт
для уже определённых состояний интерфейса.
