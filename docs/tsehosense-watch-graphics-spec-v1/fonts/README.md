# Fonts

`source/` содержит WOFF2 Roboto 400/500/600/700 для latin и cyrillic,
использованные web-прототипом.

Это authoring-ресурсы, не готовый embedded-формат. IDE должна:

1. объединить нужные unicode ranges;
2. составить subset по системным строкам и ограничениям паспортных данных;
3. растрировать каждый фактически используемый размер;
4. записать glyph metrics, baseline, advance и bitmap;
5. проверить эталонные строки;
6. включить `licenses/ROBOTO-LICENSE.txt` в дистрибутив.

Обязательные тестовые строки:

```text
20:42
AE-12 доступен
БАТАРЕЯ 78%
ТЕМПЕРАТУРА 51°
ПОРОГ −78 dBm
433.92 MHz
ПЕРЕГРЕВ ДВИГАТЕЛЯ
```

Для дисплея нельзя автоматически подменять Roboto на Roboto Condensed: это
изменит ширину, baseline и принятый вид.
